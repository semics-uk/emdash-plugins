Party packages (T174f, with Events Pro): a ticket type sold as one price for a group, for example "up to 5 people, £120". The booking form asks "How many people?" (from the type's minimum to its maximum per order) and charges the package price once. Each person still takes a place from the event or date, gets an attendee and a waiver, and per-person add-ons stay capped at one each. The booking page lists it as "Party package for 3 people". Nothing changes for events without packages.

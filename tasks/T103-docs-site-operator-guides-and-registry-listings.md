## Notes

- **Docs site** is `apps/docs` (package `docs`): Markdown in `apps/docs/pages/` plus `docs/i18n.md` and the
  protocol, rendered by `build.mjs` with `marked` (already a root dev dependency). No site generator (8 GB machine).
  The build fails on a broken link, anchor or image; repo-file links become GitHub links. `pnpm verify` gained a
  "Docs" gate after the package builds (the snippets import the built entry points).
- **Snippets** (`apps/docs/tests/snippets.test.mjs`) cover the pages, the three product READMEs and the listing
  sections. js/ts are written out and imported (each Astro config also runs the semics integrations' setup hook);
  astro is compiled with `@astrojs/compiler-rs`, imports resolved, props checked against the component's `Props`;
  the seed JSON goes through EmDash's `validateSeed`; shell lines are checked (packages, scripts, env names EmDash
  reads) and `npx emdash secrets generate` is run. Deviation: `pnpm add` / `pnpm run` lines are checked, not run;
  the protocol page's grammar and schema boxes are left to `docs/protocol/vectors.test.mjs`.
- **Screenshots**: `apps/playground/e2e/t103-screenshots.spec.ts` makes the icon (256x256), banner (1280x400) and
  screenshots (1280x800) from the running playground; `T103_WRITE=1` writes them to `packages/<core>/listing/`.
  Events lists two screenshots: a pass screenshot was dropped because the only pass in the playground shows a
  Pro QR. `listing.test.mjs` fails if a manifest names an image the spec does not make. `playwright.config.ts`
  now reads `E2E_PORT` (default 4401). Only the T103 spec was run here (port 4437), not the whole playground e2e.
- **Listings**: both manifests gained `name`, `keywords`, `sections` (`{ file }` refs into `listing/`) and
  `release.artifacts`. No capability, host, storage or route changed; changeset `docs-and-listings` (patch).
  `emdash-plugin validate` passes. Follow-up for the Pro repo: its generator copies Free's manifest, so the Pro
  manifests now carry these refs too. Harmless today (`buildPlugin` does not resolve them), but `pro.json` should
  `drop: ["sections", "release"]` before a Pro build is ever validated or published to a registry.
- **T043 answer**: EmDash 1.2 cannot scope an editor panel at run time; `collections` is a static manifest field
  (omitted means every collection). Recorded in the Events guide.
- **Legal brief §12**: README "Retention (operators)" and R45 now name the participant (minor) on the certificate
  and "Details entered by the signer"; the two §12 bullets are marked resolved.
- **T100 follow-ups** (landed on main before this finished): page caching and resubmits (R62), Pro export expiry
  (R63), the counter sweep and random IP salt (R61), MCP paid cancel/refund at 10/9 calls (R60) are in the
  configure, privacy and Events pages, with checks in `site.test.mjs`. No §12 row was needed (R70 unused).
